## 检索：先定来源标签，再看排名

64道有依据问题（原32 + 场景32），每题给定允许的来源ID。Top-1 = 第一条来源正确的题数/64；Hit@5 = 前5条至少有一个正确来源的题数/64；MRR@5 = 正确来源首次出现名次的倒数平均值，未命中记0。

| 方法 | 原始Top-1 / Hit@5 / MRR@5 | 审计后Top-1 / Hit@5 / MRR@5 |
|---|---:|---:|
| tfidf | 44/64 · 60/64 · 0.7812 | 45/64 · 61/64 · 0.7969 |
| plain_bm25 | 46/64 · 61/64 · 0.8208 | 47/64 · 62/64 · 0.8365 |
| bm25 | 57/64 · 64/64 · 0.9414 | **59/64 · 64/64 · 0.9570** |

三者共享语料、分词、字段权重和领域词替换；增强BM25另外使用模块/标题加权、同一场景分组及按问题阶段扩展子段。它是多个工程规则的组合对照，不能把全部增益归因于某一个组件。原始7条失败经逐题审计为1条等价来源标注问题、6条真实检索错误。增补1个允许来源ID后Top-1为58/64；限制手册跨阶段借分后为59/64，仍有5条失败。逐条依据及前后归因见 [检索审计](RETRIEVAL_AUDIT.md)。普通BM25原文的0.8209是合并已取整分组值的偏差；按64条原始名次重算为0.8208。

最初扩容后增强BM25场景题仅19/32，负例共17/24拒答。2026-09-27当时场景题29/32、负例24/24；本次给其中1题补等价来源后，场景题30/32。首次结果完整保留在 `expanded_before_fixes.json` 和 `expanded_before_fixes_raw.json.gz`。这不是未见样本上的泛化改进证明。Hit@5也不是最终回答准确率。
