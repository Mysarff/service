# 运行与验证记录

日期：2026-09-25。Python 3.12，本机Windows。

## 已验证

- 本地HTTP服务启动在127.0.0.1:8088，健康接口加载208个知识片段。
- 在浏览器实际点击退款问题，显示SUB-13原文与回退状态；打开知识弹窗检索ACC-13，来源全文正确。页面控制台未记录JavaScript错误。界面截图保存在 `docs/screenshot.png`。
- 10项自动检查通过：带出处原文回答、无依据问题拒答、实时订单/缺失价格拦截、非法JSON处理、过大请求头拒绝、跨来源写入拒绝、长文本尾部保留、重复导入去重、模块筛选和伪造引用回退。
- 32道正例：当前检索Top-1为30/32，Hit@5为32/32；完整对照与失败案例见 `evaluation/results.json`。
- 12道负例：开发初期10/12拒答，明确实时数据和缺失政策边界后12/12拒答。规则经过这些失败案例修正，因此该集合是开发回归集，不是未见测试集。改前记录保留在 `evaluation/before_capability_gate.json`。

## 真实模型调用边界

使用本机提供的模型配置完成端到端尝试，模型服务返回HTTP 401 / invalid_api_key。问题“忘记密码”和“取消自动续费”均正确进入原文回退，返回对应ACC-13、SUB-13来源；具体订单查询进入无依据提示。此时没有成功取得真实大模型生成答案，不能把原文回退写成模型调用成功。结果见 `evaluation/live_smoke_results.json`。

使用者可以在自己的本地配置中提供有效模型凭据，再运行 `python evaluation/live_smoke.py` 复核。配置齐全与实际认证成功是不同状态，页面对每条回答显示实际模式。
