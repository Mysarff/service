# 2026-09-30 对话与本地 HTTP 边界修复

## 修复范围

- 短追问从最近的用户主题向前解析一次，连续“然后呢 / 还有呢”保留原主题；新的完整问题重置主题。检索、能力边界判断和模型最终问题使用同一解析结果，避免实时订单、企业收款账户等被拒问题通过追问绕过限制。
- 在 HTTP 请求分派前校验唯一 Host，只允许实际监听端口上的 `127.0.0.1` / `localhost`，覆盖读写接口和静态页面；已有 POST Origin 校验保留。此项减少攻击者域名解析到回环地址时的 DNS rebinding 风险，不是登录或权限系统。
- 历史消息必须含 `user` / `assistant` 角色及字符串 `content`，缺失字段等无效输入返回 400，避免后续访问字段时产生 500。
