# 简历可用表述与证据边界

## 可直接使用的项目描述

**CloudCare 企业客服知识库（个人工程项目，合成业务数据）**

- 构建覆盖16个业务模块的知识库，整理112份来源文档、592个可追溯片段，配套生成4,736条FAQ问法和24,000条模拟工单，实现来源映射、内容去重与SHA-256完整性校验。
- 实现BM25倒排检索、模块加权、场景分组与子段扩展；逐题审计等价来源并限制跨阶段借分后，在64道自建开发回归题上Top-1为59/64、Hit@5为64/64、MRR@5为0.9570，尚有5题Top-1失败。
- 完成18项功能与检索审计检查；实现模型调用异常与无效引用回退。2026-09-27旧代码的本机HTTP短测6,000次成功，8并发P95为21.58 ms；本次检索修改后未重测性能。

## 面试时必须能解释

1. 592是切分片段数，不是独立事实数；24,000条模拟工单不进入知识索引。来源规则由开发者编写，未接入真实企业资料。
2. 64题是参与过调试的开发回归，另外24题检验拒答；不能称为独立测试或真实客服准确率。原始7条失败中1条是等价来源标签，1条经排序修复，当前仍有5题失败。
3. 倒排索引减少无共同词项文档的扫描；当前64题的全量扫描与倒排排名一致。旧版本的640/640计时与27.2%平均耗时差异不能直接作为新版本性能数字。
4. HTTP测试关闭外部模型，每组仅数秒；8并发最大耗时约1.03秒。不能写成大模型毫秒级回答或企业生产SLA。
5. 真实模型尚缺有效配置完成验收。可以写“实现兼容模型接口”，不能写“已完成真实模型端到端验证”。
6. 没有实现Milvus、BGE向量/重排、BERT分类、多租户权限或真实退款/审批。与教育版共享RAG步骤，但不是完整技术栈迁移。
